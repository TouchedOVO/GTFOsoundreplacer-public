# GTFOSoundReplacer 使用说明

插件为 GTFO 提供音效列表和 SoundBank 事件映射。运行环境为 BepInEx 6 IL2CPP，默认按 F8 打开界面，也可在配置中修改快捷键。

## 安装

将插件 DLL 放入 `GTFO/BepInEx/plugins/GTFOSoundReplacer/`，将自定义 `.bnk` 放入 `GTFO/BepInEx/Assets/SoundBank/`。首次运行会创建 SoundBank 和预设目录。

普通音频文件需要先通过 Wwise 制作成 SoundBank，具体过程见 [SoundBank 使用指南](SoundBank使用指南.md)。

## 名称与翻译

插件启动后会从本机游戏音库建立事件目录，并保留缓存。相同事件 ID 在列表中只显示一次。按 F8 后可勾选“显示翻译”；默认关闭，但中文搜索始终可用。没有名称资料时显示数字 ID。

中文翻译会从配置地址后台下载并保存在 `BepInEx/plugins/GTFOSoundReplacer/catalog/zh-CN.json`。下载失败时继续使用已有文件。也可手动安装该文件，然后重启游戏。翻译属于粗翻，可能与实际声音存在差异。详细见 [翻译说明](../catalog/README.md)。

## 分配与试听

1. 按 F8 打开界面，通过搜索框查找名称或事件 ID，也可按分类浏览。
2. 点击目标行的选择音频，打开音库事件分配面板，再点击加载音库目录。
3. 填入自定义事件的数字 ID，点击分配音库事件，再勾选该行的启用。
4. 点击 ▶ 试听替换事件，点击原试听游戏事件。最后在实际游戏中触发一次确认效果。

启动后需加载要使用的 SoundBank。当前已加载的同路径文件会直接复用，修改音库后重启游戏再加载。取消启用或清除替换后，目标事件恢复经过游戏原来的播放流程。

单项和全局音量均可在界面调整，数值范围为 0 到 2。单项音量乘以全局音量后，最终倍率上限为 2。替换音量为 0 时不播放替换声音；若该项仍启用静音原音，原音也会被跳过。

所有替换与试听共享发声对象，输出增益会影响同一对象上的其他声音，设置为 1 的播放也可能沿用之前的增益。它不能提供每个播放实例相互独立的音量控制。

## 预设

在预设栏填入名称后保存。加载会用该预设覆盖当前映射；删除会移除对应的 JSON 文件。导出会在预设目录的 `exports/` 下生成同名 JSON 副本，并将路径写入日志，原预设保持不变。分享时复制导出的文件即可。

导入时，在同一个输入框填入 JSON 文件的完整路径，再点击导入。导入会将文件保存到预设目录，成功后自动在输入框填入预设名，再点击“加载”应用。保存、加载、导入、导出和删除的结果会短暂显示在界面右下角。预设目录为 `BepInEx/plugins/GTFOSoundReplacer/presets/`。

正常退出时，当前映射保存到 `_autosave.json`。启动时优先加载配置中的默认预设，否则恢复自动保存。需要立即保存的修改可手动保存为命名预设。

预设只包含目标事件、启用状态、音量、静音原音和替换事件 ID。分享预设时还需提供对应 SoundBank：

```json
{
  "name": "我的预设",
  "entries": [
    {
      "eventId": 2542276107,
      "enabled": true,
      "volume": 1.0,
      "muteOriginal": true,
      "bankEventId": 90001234
    }
  ]
}
```

示例 ID 需替换为实际数值。`muteOriginal` 为 true 时，替换提交成功后跳过游戏原事件；为 false 时，两者都会提交播放。该选项可在预设中编辑，界面没有单独的静音原音按钮。游戏原事件可能包含音量控制等附加动作，跳过它也会跳过这些动作。

## 配置与排查

配置文件由 BepInEx 在 `BepInEx/config/` 下生成，文件名通常为 `dev.gtfo.GTFOSoundReplacer.cfg`。

| 配置项 | 用途 |
| --- | --- |
| `Hotkey` | 界面主键，默认 F8 |
| `HotkeyModifier` | None、Ctrl、Shift 或 Alt |
| `GlobalVolume` | 全局音量倍率 |
| `DefaultPreset` | 启动时优先加载的预设名 |
| `MuteOriginalDefault` | 新建条目的静音原音默认值 |
| `LogEventIds` | 将拦截到的事件名称和 ID 写入日志 |
| `[Catalog] TranslationUrl` | 翻译 JSON 的 HTTPS 直链；可更换，留空关闭下载 |

试听无声时，先检查 SoundBank 加载结果、事件 ID 和音量。事件必须包含在已加载的音库中。插件检测到替换提交失败会放行游戏原音，但提交成功不保证素材最终可听。

需要定位游戏事件时，开启 `LogEventIds`，触发声音后查看 `BepInEx/LogOutput.log` 中的 `[SR-ID]`。列表不代表所有事件都经过已覆盖的播放入口，部分对白或音乐可能无法替换。自定义素材的定位和混响也应在关卡中实际检查。

默认翻译地址为 `https://raw.githubusercontent.com/TouchedOVO/GTFOsoundreplacer-public/1.0.3/catalog/zh-CN.json`。该地址只是 DLL 提供的初始值；已有配置会保留。修改配置前退出游戏。首次下载失败且没有本地翻译时仍可使用数字 ID 查找和分配音效。
