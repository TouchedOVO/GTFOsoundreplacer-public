# 音效目录

1.0.3 启动时在后台扫描游戏 GeneratedSoundBanks/Windows 下的 BNK，从 HIRC 事件定义提取数字 ID。相同 ID 在用户列表合并为一项，保留来源音库记录。目录供查找和日志使用，替换播放仍按数字 ID 路由。

## 缓存与变化检测

缓存位于插件目录的 `catalog/events.cache.json`。对建库依赖的 BKHD、HIRC、STID 结构区块计算带边界的摘要，不读取 DATA 媒体负载来计算摘要。后续启动仍需读取事件结构；结构与输入清单未变化时复用名称及分类缓存，跳过对应名称解析与缓存重写。

本地存在可用 TXTP 时可补充原名与分类；只有 BNK 时仍可列出事件 ID。BNK 事件定义不保证携带原名。旧版生成源码保留作参考，但已从生产编译中排除。运行时不逐个计算原名的 Wwise HASH，也不逐个试播来验证事件。

## 中文映射

`catalog/zh-CN.json` 按事件 ID 提供原名、中文和分类。启动先读本地文件，再按配置的 HTTPS 直链尝试后台更新。下载须通过格式、大小和字段检查才写入；失败保留已有文件。没有翻译或原名时退回 ID。名称发生冲突时避免错误关联翻译。

同一 ID 共用一份翻译。目录构建或下载完成后发布内存快照，界面刷新索引；正常播放与换局不重新读取目录文件。显示翻译开关只改变名称显示，不触发下载或重新建库。

## 验证边界

事件存在于 BNK 只说明有事件定义，不证明对应音库已加载、媒体可用或实际可听。目录失败不应阻断原来的音效播放路径。数据格式和缓存回退由目录测试覆盖，实际可听性由游戏内试听及自然触发确认。
