# 音效目录（1.0.5）

插件启动后在后台读取本机游戏BNK结构，建立事件目录和本地缓存。同一数字事件ID在列表中仅显示一次，缓存保留其音库来源。目录生成不播放声音，也不把音库定义存在当成实际可听保证。

## 缓存与名称

当前实现支持BNK版本118和125，从HIRC提取事件ID；读取BKHD、HIRC和STID结构计算SHA256，跳过媒体DATA，比较音库清单及结构指纹后复用或重建缓存。TXT是可选名称来源，只有BNK也能建数字ID目录。

中文翻译提供可用的原名、分类和中文文本，启动时后台下载到catalog/zh-CN.json；失败保留本地文件。没有名称资料时仍可按数字ID操作。不要求每个用户具备wwiser导出的TXT或TXTP。

运行时不再使用SoundCatalogData.generated.cs内置目录，该历史生成文件也不参与主工程编译。tools/gen-catalog.ps1保留用于离线参考资料生成，不是用户启动的必需步骤。

## 使用

按F8按名称、数字ID或分类搜索。显示翻译默认关闭，中文搜索始终可用。自定义SoundBank的事件ID需自行填入，它与被替换的游戏事件ID是两个不同用途的编号。详见[用户文档](用户文档.md)。
