# SoundBank 使用指南

GTFOSoundReplacer 通过 Wwise 播放 `.bnk` 中的事件。准备音频后，需要在 Wwise Authoring 中制作事件并生成 Windows SoundBank。Authoring 版本应与游戏音频引擎兼容，具体版本需根据目标游戏环境核对。

## 制作音库
前置：下载 Wwise Authoring，版本号为2017.1.9.6501版本，该版本为GTFO声音库默认构建版本，其他版本未经测试，可能存在不兼容的报错问题，作者并不能提供兼容帮助。

1. 创建 Wwise 工程，启用 Windows 平台。
2. 在 Actor-Mixer Hierarchy 中导入音频，创建 Sound SFX。
3. 创建 Event，为它添加播放该声音的 Play 动作。
4. 创建 SoundBank，将 Event 加入音库，并确保需要的媒体一并包含。
5. 生成 Windows 平台的 SoundBank，找到生成的 `.bnk`。

如需随机播放，将多段声音放入 Random Container，再让 Event 播放这个容器。随机规则由 Wwise 工程决定，插件仍使用同一个事件 ID。

首次测试建议先制作一个简单、非流式且包含媒体的音库，确认可以在游戏中播放后再增加行为。若素材依赖外部媒体、其他音库或额外插件，需要自行确认目标环境具备这些资源。

## 获取事件 ID

插件需要 Event 的数字 Short ID。可在 Wwise 的事件属性或生成的事件 ID 文件中查找，例如 `Wwise_IDs.h`。填入的是自定义事件 ID，与要替换的游戏事件 ID 分开记录。

一个 SoundBank 可以包含多个事件，多个游戏音效也可以映射到同一个自定义事件。为事件使用清晰、独特的名称，并保留工程及 ID 对照，便于之后更新。

## 在游戏中分配

1. 将 `.bnk` 复制到 `GTFO/BepInEx/Assets/SoundBank/`。目录扫描只读取该层的 `.bnk` 文件。
2. 启动游戏并按 F8，找到目标游戏音效，点击选择音频。
3. 点击加载音库目录，确认状态显示加载成功。
4. 输入自定义事件的数字 ID，点击分配音库事件，再启用目标行。
5. 点击 ▶ 试听，再在关卡中触发目标音效检查效果。

修改已加载的音库文件后，需要重启游戏再加载。保存预设只保存事件映射，分享时应将对应 `.bnk` 一并提供。

## 加载或播放失败

加载失败时查看 `BepInEx/LogOutput.log` 中的 `Failed to load SoundBank` 及返回值。版本不兼容、文件不完整和依赖缺失都需要分别核对。

加载成功但试听无声时，检查事件是否加入了该音库、Play 动作是否指向有效声音、媒体是否包含，以及界面音量和游戏声音设置。需要位置、距离衰减或混响的事件还应在实际关卡中确认；实际替换使用插件的发声对象，试听使用独立对象；空间效果不会自动等同于原事件。
